# Page view grader

Moodle local plugin `local_pagegrader`.

Awards a grade automatically when a learner views a page activity, driven by Moodle event observers.

## Requirements

- Moodle with version number `2020110900` or later.

## Installation

Copy the plugin folder to `local/pagegrader` in your Moodle root, then visit
**Site administration → Notifications** to complete the database upgrade.

```
<moodle>/local/pagegrader
```

## Version

Release `1.3`. See `version.php` for the exact version number.
